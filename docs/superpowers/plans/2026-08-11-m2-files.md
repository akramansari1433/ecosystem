# M2 File Browsing Implementation Plan

> Executes the M2 section of the approved design (docs/superpowers/specs/2026-08-11-ecosystem-design.md) with one requirement change from the user: **drag & drop both ways** (drag a phone file from the window into Finder to download; drop Finder files onto the window to upload). Buttons remain as secondary affordances.

**Protocol change:** the client now speaks first on every connection (`hello` → control, `stream.attach` → stream); the phone no longer sends `hello` unprompted (docs/protocol.md §4 updated). Six `fs.*` fixture cases added to envelope.json.

## Tasks

1. **Kotlin fs payloads + codec cases** (TDD vs new fixtures): FsEntry(isDir, mtimeMillis, name, size) — alphabetical declarations; FsList/FsEntries/FsDownload/FsUpload/FsTransferReady/FsTransferResult messages.
2. **Kotlin BinaryFrame codec** (TDD vs binary-frames.json): encode/decode `[len][type][ptsMicros][payload]`, incremental reader.
3. **Kotlin FileService pure logic** (TDD): path canonicalization guard (must stay under root), listing to FsEntry, SHA-256 accumulation.
4. **Swift mirrors of 1–3** (TDD, same fixtures).
5. **Android integration:** first-frame branching in ConnectionService (hello→control, stream.attach→stream — stream connections must NOT displace the control session); transfer registry (token → pending download/upload); stream runner sending/receiving 256 KiB chunks; MANAGE_EXTERNAL_STORAGE settings-intent card in MainActivity; capabilities += "fs".
6. **Mac integration:** StreamConnection actor (dial pinned, send attach, stream binary frames); TransferManager (download to temp/Downloads with SHA-256 verify + fs.transferResult; upload from URLs).
7. **Mac UI:** "Browse phone files…" menu item → Window scene: Table (name/size/modified), double-click to enter dirs, breadcrumb, Refresh, Upload button; **drag OUT** via Transferable FileRepresentation (async download on drop); **drag IN** via .dropDestination(for: URL.self).
8. **E2E:** list DCIM, download >10 MB file with hash check, upload file visible in My Files, drag both directions, cancel safety.
